## Review Expectations

Changes touching authentication, quota/credit logic, API key handling, server routes, deployment templates, Docker files, or dependency versions require careful maintainer review before merge.

Third-party deployment buttons, external scripts, analytics, or new hosted-service integrations should not be merged unless the maintainer has verified the provider, permission model, and deployment behavior.
